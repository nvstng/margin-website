margin-website / commands

Development

npm run dev local
Start the Astro dev server with hot reload.
Runs on http://localhost:4321 by default.
npm run preview
Preview the production build locally.
Run npm run build first.

Build

npm ci
Install exact dependencies from package-lock.json.
Use this instead of npm install for reproducible builds.
npm run build prod
Compile and emit static site into dist/.

Package & Deploy

npm run package:local
Full build + package into a deployable tarball.
Runs scripts/package-local.sh — output at /tmp/margin-artifacts/margin-website-deploy.tar.gz
bash scripts/package-local.sh
Same as above, invoked directly.
Steps: npm ci → npm run build → tar into /tmp/margin-artifacts/
